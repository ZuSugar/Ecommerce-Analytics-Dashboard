# Ecommerce-Analytics-Dashboard

## Overview
End-to-end analytics project on a 500K-order dataset (2020–2023).
From raw data cleaning to a 4-page interactive Power BI dashboard.

## Key Metrics
- 500K orders | 382M total revenue
- 40.45% return rate | 20.00% churn rate
- 50,000 unique customers across 4 product categories

## Tools
- Python (Pandas) — data cleaning, 1.5M rows
- Scikit-learn — Random Forest churn prediction
- Power BI — 4-page interactive dashboard

## Dashboard Pages
| Page | Purpose |
|---|---|
| Overview | Revenue, orders, returns by category & age |
| Return Analysis | Return rate by category, age, gender |
| Churn Analysis | Churn rate, revenue lost, at-risk segments |
| Customer Segments | Avg order value, revenue per customer |

## Key Findings
- 55+ age group has highest order volume (150K) and spending
- Under-25 group shows highest churn rate (21%)
- Clothing and Books generate more revenue than Electronics and Home
